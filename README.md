# Калькулятор особистого бюджету — квартальний звіт

Навчальний застосунок на Python 3.10+, Streamlit і pandas для ведення трьох місячних бюджетів та формування квартального звіту. Сторонні UI-бібліотеки не використовуються.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

У Windows активуйте середовище командою `.venv\Scripts\activate`.

## Використання

1. У бічній панелі виберіть «Місячні дані».
2. На вкладці кожного місяця введіть дохід і витрати у гривнях: їжа, транспорт, розваги, житло / комунальні, інше.
3. Натисніть «Розрахувати», щоб зберегти результат. З’являться таблиця, діаграма, сума витрат, баланс і статус бюджету.
4. Перейдіть до «Квартальний звіт», щоб побачити загальні показники та витрати за категоріями.
5. Після розрахунку всіх трьох місяців завантажте `quarterly_budget.csv`.

Нульові значення допустимі; навіть місяць без доходів і витрат потрібно підтвердити кнопкою. Від’ємні суми заборонені. Для неповного кварталу показуються попередні підсумки з переліком відсутніх місяців; CSV недоступний до завершення кварталу.

Чернетки та результати зберігаються у `st.session_state` і переживають перемикання розділів. Звіт використовує останній збережений розрахунок: після редагування повторно натисніть «Розрахувати». Дані тимчасові: нова сесія чи перезапуск сервера їх скидає. Застосунок не записує бюджет у файли; CSV формується в пам’яті для завантаження.

## CSV

Експорт має українські назви колонок і категорій відповідно до оригінальних тестів, кодування UTF-8 із BOM, 15 рядків витрат і три підсумкові рядки. Заголовок у файлі один.

```csv
Місяць,Категорія,Сума
Місяць 1,Їжа,3000.0
Місяць 1,Транспорт,1000.0
```

Наприкінці файлу:

```csv
ВСЬОГО,ДОХІД,30000.0
ВСЬОГО,ВИТРАТИ,24000.0
ВСЬОГО,БАЛАНС,6000.0
```

Суми тут наведено як приклад. Категорії: `Їжа`, `Транспорт`, `Розваги`, `Житло / Комунальні`, `Інше`.

## Код і перевірки

- `streamlit_app.py`: інтерфейс, повторно використовувані функції розрахунку, об’єднання через `pd.concat`, агрегація через `groupby` та експорт.
- `test_streamlit_app.py`: оригінальні тести розрахунків, агрегації та CSV.
- `.github/workflows/ci.yml`: запуск тестів у GitHub Actions.

```bash
pytest -v test_streamlit_app.py
```
